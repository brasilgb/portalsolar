# Maps Address Extractor — Chrome

Extensão simples para capturar a empresa atualmente aberta no Google Maps.

## Campos
- Nome
- Endereço
- Latitude
- Longitude
- URL da imagem encontrada na página
- URL do Google Maps
- Data/hora da captura

## Instalação
1. Extraia o ZIP.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta extraída.

## Uso
1. Abra o Google Maps.
2. Pesquise e abra o painel de uma empresa.
3. Clique na extensão.
4. Clique em **Capturar empresa atual**.
5. Repita para outras empresas.
6. Clique em **Exportar CSV**.

Observação: o Google Maps altera o HTML periodicamente; seletores podem precisar de ajustes futuros.
